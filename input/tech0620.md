# 一、这三个 Pipeline 本质区别是什么？

它们不是“模型不同”，而是：

> **输入图像 + 用户意图 + 期望输出结构不同**

---

## 1. Product Image Pipeline（电商商品图）

### 核心目标：

👉 “让商品看起来可卖”

### 输入特征：

* 产品为主体（单物体）
* 背景通常杂乱
* 需要“商业级视觉”

### 输出目标：

* 白底图（Amazon）
* Studio光影
* 阴影/反射增强
* 干净边缘
* 真实感提升

### 典型任务：

* 去背景
* 统一光照
* 补光/柔光
* 产品摆拍生成

---

## 2. Portrait Pipeline（人像）

### 核心目标：

👉 “让人看起来更好看，但不能变形”

### 输入特征：

* 人脸关键结构敏感
* 皮肤、五官不能乱改
* 发丝边缘极其重要

### 输出目标：

* 美化但保持身份
* 背景替换
* 光线优化
* 证件照/头像适配

### 典型任务：

* 去背景（人像）
* 美颜但不换脸
* 背景虚化
* 表情增强（轻微）

---

## 3. Generic Editing Pipeline（通用编辑）

### 核心目标：

👉 “一切都可以改，但不保证结构严格”

### 输入特征：

* 任意图片
* 不确定主体类型

### 输出目标：

* 遵循 prompt
* 更偏“生成式重绘”
* 允许更自由变化

### 典型任务：

* 加物体
* 换风格
* 局部重绘
* 场景改造

---

# 二、核心区别一句话总结

```text id="core_diff"
Product → 商业真实（卖货）
Portrait → 身份保持（不能变脸）
Generic → 自由生成（允许变化）
```

---

# 三、能不能用同一个 GPT Image2 模型？

## 结论先说：

> ✅ 可以用同一个模型（GPT Image2）
> ❗ 但必须做“前置路由 + prompt engineering + mask控制”

---

# 四、GPT Image2 在这里的真实定位

你对接的 GPT Image2，本质是：

> 🔥 “通用图像生成 + 编辑模型（Diffusion + instruction guided editing）”

它不是：

* ❌ 专用人像模型
* ❌ 专用商品摄影模型
* ❌ 专用抠图模型

---

# 五、正确架构：不是3个模型，而是1个模型 + 3个“控制器”

## ✔ 推荐架构（重点）

```text id="arch_1"
                 ┌──────────────┐
User Image + Prompt ──► Task Router │
                 └──────┬───────┘
                        ↓
        ┌─────────────────────────────────┐
        │ Prompt + Mask + Context Builder │
        └─────────────────────────────────┘
                        ↓
              GPT Image2 API
                        ↓
                 Output Image
```

---

# 六、关键：三种 Pipeline = 三种 Prompt策略

## 1. Product Pipeline Prompt（最重要）

你要“约束模型行为”

### Prompt模板：

```text id="prompt_product"
Transform this product image into a professional e-commerce studio photo.

Requirements:
- Keep product shape exactly unchanged
- White or neutral studio background
- Soft studio lighting
- Realistic shadow under product
- High-end commercial photography style
- Remove all distractions
```

👉 关键：**强约束结构 + 商业摄影风格**

---

## 2. Portrait Pipeline Prompt

```text id="prompt_portrait"
Enhance this portrait photo while preserving identity.

Requirements:
- Do not change facial structure
- Preserve identity
- Improve lighting and skin tone naturally
- Optionally change background
- Keep hair detail realistic
- Professional headshot quality
```

👉 关键：**identity preservation（身份锁定）**

---

## 3. Generic Pipeline Prompt

```text id="prompt_generic"
Edit this image based on the instruction while keeping overall coherence.

Instruction: {user_prompt}

Maintain realism unless stylization is requested.
```

👉 关键：**开放性最大**

---

# 七、是否真的需要拆 Pipeline？

## 现实答案（很重要）：

### ❌ 不拆也能跑 MVP

只用 GPT Image2 + prompt

---

### ✔ 但上线产品必须拆 Pipeline

原因不是技术，而是：

## 1. 成功率差异巨大

| 类型  | 成功率 |
| --- | --- |
| 商品图 | 高   |
| 人像  | 中   |
| 通用  | 不稳定 |

---

## 2. 用户预期完全不同

* 商品图用户：不能乱改
* 人像用户：不能变脸
* 通用用户：可以接受变化

👉 不拆 pipeline = 用户投诉爆炸

---

## 3. 商业转化不同

| Pipeline | 付费意愿  |
| -------- | ----- |
| Product  | ⭐⭐⭐⭐⭐ |
| Portrait | ⭐⭐⭐⭐  |
| Generic  | ⭐⭐⭐   |

---

# 八、真正工程关键：不是模型，而是 3 个控制器

你真正要做的是：

---

## 1. Task Classifier（任务识别）

输入：

* image
* prompt

输出：

```text id="classify"
product / portrait / generic
```

可以用：

* GPT classify
* rule-based（检测人脸/物体）
* CLIP embedding

---

## 2. Mask Generator（区域控制）

非常关键：

| pipeline | mask策略                   |
| -------- | ------------------------ |
| product  | product segmentation     |
| portrait | face + hair protection   |
| generic  | full image or user brush |

---

## 3. Prompt Builder（最重要）

最终决定效果：

```text id="builder"
final_prompt = system_prompt[pipeline] + user_prompt + constraints
```
